║                    WHAT TO DO NOW (3 STEPS)                          ║
╚══════════════════════════════════════════════════════════════════════╝

STEP 1: Install Dependencies
────────────────────────────────────────────────────────────────────────
Open terminal and run:

    cd Backend\fake-internship-detector-backend
    npm install


STEP 2: Get Google OAuth Credentials
────────────────────────────────────────────────────────────────────────
1. Visit: https://console.cloud.google.com/
2. Create OAuth 2.0 Client ID
3. Redirect URI: http://localhost:3001/auth/google/callback
4. Copy Client ID and Secret

📖 Detailed guide: Open GOOGLE_OAUTH_SETUP.md


STEP 3: Update .env File
────────────────────────────────────────────────────────────────────────
Edit: Backend\fake-internship-detector-backend\.env

Replace these two lines:
    GOOGLE_CLIENT_ID=your_google_client_id_here.apps.googleusercontent.com
    GOOGLE_CLIENT_SECRET=your_google_client_secret_here

With your actual credentials from Google Console


╔══════════════════════════════════════════════════════════════════════╗
║                         START SERVERS                                ║
╚══════════════════════════════════════════════════════════════════════╝

Backend (Terminal 1):
    cd Backend\fake-internship-detector-backend
    npm start

Frontend (Terminal 2):
    cd Frontend
    npm run dev
