╔══════════════════════════════════════════════════════════════════════╗
║                  TROUBLESHOOTING                                     ║
╚══════════════════════════════════════════════════════════════════════╝

ERROR: "npm: command not found"
────────────────────────────────────────────────────────────────────────
Problem: Node.js not installed
Fix: Download and install from https://nodejs.org/
     Choose LTS version (recommended)


ERROR: "Port 3000 already in use"
────────────────────────────────────────────────────────────────────────
Problem: Another app is using port 3000
Fix: 
  1. Find what's using it:
     netstat -ano | findstr :3000
  
  2. Kill the process (replace 1234 with actual PID):
     taskkill /PID 1234 /F
  
  3. Or change port in Frontend/package.json


ERROR: "Module not found" or "Cannot find module"
────────────────────────────────────────────────────────────────────────
Problem: Dependencies not installed properly
Fix:
  1. Delete node_modules folder
  2. Delete package-lock.json
  3. Run: npm install again


ERROR: Backend starts but shows errors
────────────────────────────────────────────────────────────────────────
Problem: .env file might be corrupted
Fix:
  1. Check Backend/fake-internship-detector-backend/.env exists
  2. Verify it has JWT_SECRET and SESSION_SECRET
  3. If missing, copy from .env.example


Website loads but looks broken (no styling)
────────────────────────────────────────────────────────────────────────
Problem: Frontend build issue
Fix:
  1. Stop frontend server (Ctrl+C)
  2. Delete Frontend/.next folder
  3. Run: npm run dev again
